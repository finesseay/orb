what is TraceLayer?

TraceLayer is a governed task platform. You work through conversation. Project manager agents organise and brief the work. Governed workers execute it. The platform records the evidence and brings finished results to you for review.

does every message create a task?

No. Questions, brainstorming, and status requests stay conversational. A clear request to do work creates or continues the matching task. Filing work and starting work are separate choices.

what does “governed” mean?

The platform fixes the worker's scope, workspace, capabilities, brief, and verification requirements before work starts. A prompt or tool cannot silently widen them.

how do I know the result is real?

Each run keeps its brief, node history, checks, checkpoint, and delivery evidence. The board only moves finished agent work to Review when the required evidence exists.

can an agent mark work complete?

No. The platform moves verified work to Review. Only you can move it to Complete, request an amendment, or explicitly close unfinished work.
